# v8-cf-set-form-elem-prop

## Назначение

Скилл изменяет геометрическое свойство элемента (поля ввода, надписи и т.п.)
на обычной форме справочника в исходниках 1С, распакованных v8unpack.

Поддерживаемые свойства: `width` (ширина), `height` (высота),
`left` (левый отступ), `top` (верхний отступ).

## Использование

- «установи ширину элемента Код формы ФормаЭлемента справочника Справочник01 равной 200»
- «измени высоту поля Наименование до 50 пикселей»
- «сдвинь поле Код вправо до x=100»
- «set left of Код to 100»

## Инструменты

### `tools/form_elem_props.py`

Модуль с определениями свойств и функцией `apply_prop(raw, prop, new_val)`.
Импортируется `set_form_elem_prop.py`.

### `tools/set_form_elem_prop.py`

Основной CLI-скрипт:

```
python tools/set_form_elem_prop.py <source_dir> <catalog_name> <form_name> <elem_name> <prop> <new_value>
```

Аргументы:
- `source_dir`   — путь к распакованным исходникам
- `catalog_name` — имя папки справочника (например, `Справочник01`)
- `form_name`    — имя обычной формы (например, `ФормаЭлемента`)
- `elem_name`    — системное имя элемента на форме (например, `Код`)
- `prop`         — свойство: `width`/`ширина`, `height`/`высота`, `left`/`лево`, `top`/`верх`
- `new_value`    — новое значение в пикселях (целое число ≥ 0)

## Примеры

```bash
# Сузить поле Код до 200 пикселей
python tools/set_form_elem_prop.py ref_sources/step_0039 Справочник01 ФормаЭлемента Код width 200

# Изменить высоту поля Наименование
python tools/set_form_elem_prop.py src/BAU Справочник01 ФормаЭлемента Наименование height 50

# Сдвинуть поле Код (изменить левый отступ)
python tools/set_form_elem_prop.py src/BAU Справочник01 ФормаЭлемента Код left 100

# Изменить верхний отступ
python tools/set_form_elem_prop.py src/BAU Справочник01 ФормаЭлемента Код top 50
```

## Определение source_dir

Путь к исходникам берётся из `v8.projects.json`:

- Топ-уровневый проект (например, `BAU`): `projects.BAU.src` = `src/BAU`
- Подпроект (например, `BAU_KlientBank`): `projects.BAU.projects.BAU_KlientBank.src` = `src/BAU/BAU_KlientBank`

## Что изменяет скрипт

### 1. `CatalogForm.elem.json`

Файл находится по пути:
```
source_dir/Catalog/<catalog_name>/CatalogForm/<form_name>/CatalogForm.elem.json
```

Структура записи элемента в `data`:
```json
"Страница1/Код": {
  "ver": ...,
  "raw": [
    "<form-type-uuid>",    // raw[0] — UUID типа формы
    "7",                   // raw[1] — индекс элемента в форме
    ["9", ...],            // raw[2] — дескриптор элемента
    ["8", x, y, w, h, ... ],  // raw[3] — геометрия (см. ниже)
    ["14", '"Код"', ...],  // raw[4] — заголовок (надпись)
    ["0"]                  // raw[5] — дочерние элементы
  ]
}
```

#### Геометрический блок `raw[3]`

```
raw[3] = [
  "8",        // [0] маркер типа геометрии
  x,          // [1] ★ ЛЕВО  (left)  — пикселей от левого края страницы
  y,          // [2] ★ ВЕРХ  (top)   — пикселей от верхнего края страницы
  w,          // [3] ★ ШИРИНА (width) — пикселей (VERIFIED)
  h,          // [4] ★ ВЫСОТА (height) — пикселей
  "1",        // [5] флаг
  anchor_L,   // [6] привязка левого края
  anchor_T,   // [7] привязка верхнего края
  anchor_R,   // [8] привязка правого края
  anchor_W,   // [9] привязка ширины / правой границы (VERIFIED)
  anchor_H5,  // [10] привязка высоты (5)
  anchor_H6,  // [11] привязка высоты (6)
  ...         // прочие поля
]
```

Структура якоря:
```json
["0", ["2", ref_idx, side, offset], ["2", "-1", "6", "0"]]
```
- `ref_idx = "-1"` — якорь неактивен
- `ref_idx = "0"`  — опора на форму/страницу
- `ref_idx = str(elem_idx)` — самоссылка (элемент опирается на себя)

#### Правила обновления якорей при изменении свойства (VERIFIED — width)

| Свойство | Скаляр      | anchor_L [6]   | anchor_T [7] | anchor_W [9]                            | anchor_H5/H6 [10/11]  |
|----------|-------------|----------------|--------------|-----------------------------------------|-----------------------|
| `width`  | raw[3][3]   | —              | —            | `+delta` если активен (VERIFIED)        | —                     |
| `height` | raw[3][4]   | —              | —            | —                                       | `+delta` если активны |
| `left`   | raw[3][1]   | `+delta` если активен | —     | самоссылка → `-delta`; иначе `+delta`   | —                     |
| `top`    | raw[3][2]   | —              | не изменяется¹ | —                                    | —                     |

¹ anchor_T имеет самоссылку с offset=19 — это НЕ абсолютная координата y
(проверено: у Код (y=33) и Наименование (y=58) оба имеют offset=19).

#### Примеры значений якоря anchor_W из шагов 0040–0043

| Элемент         | Шаг   | w     | anchor_W                          |
|-----------------|-------|-------|-----------------------------------|
| Страница1/Код   | 0039  | `384` | `ref=7, side=2, offset=348`       |
| Страница1/Код   | 0040  | `135` | `ref=7, side=2, offset=99`        |
| Страница1/Код   | 0041  | `384` | `ref=7, side=2, offset=348`       |
| Страница1/Наим. | 0041  | `384` | `ref=0, side=3, offset=-8`        |
| Страница1/Наим. | 0042  | `237` | `ref=0, side=3, offset=-155`      |
| Страница1/Наим. | 0043  | `384` | `ref=0, side=3, offset=-8`        |

Закономерность: `new_offset = old_offset + (new_width - old_width)`.

Детали всех якорей для Код и Наименование (step_0039):
```
=== Страница1/Код (elem_idx=7) ===
  x=36  y=33  w=384  h=52
  anchor_L [6]:  ref=-1 side=6 off=0
  anchor_T [7]:  ref=7  side=0 off=19   ← самоссылка, off ≠ y (33≠19)
  anchor_R [8]:  ref=-1 side=6 off=0
  anchor_W [9]:  ref=7  side=2 off=348  ← самоссылка, off = w−x = 384−36 (VERIFIED)
  anchor_H5 [10]: ref=-1
  anchor_H6 [11]: ref=-1

=== Страница1/Наименование (elem_idx=11) ===
  x=93  y=58  w=384  h=77
  anchor_L [6]:  ref=-1 side=6 off=0
  anchor_T [7]:  ref=11 side=0 off=19   ← самоссылка, off ≠ y (58≠19)
  anchor_R [8]:  ref=-1 side=6 off=0
  anchor_W [9]:  ref=0  side=3 off=-8   ← ссылка на форму, off = right−form_right
  anchor_H5 [10]: ref=-1
  anchor_H6 [11]: ref=-1
```

### 2. `CatalogForm.json`

Путь: `form[0][0][1][10]` — счётчик ревизий формы (строка с целым числом).
Дизайнер увеличивает его на 1 при каждом редактировании формы.
Скрипт повторяет это поведение.

## Ограничения

- Поддерживает только **обычные формы** (binary-формат `Form.bin`, источник в
  `CatalogForm.elem.json`). Для управляемых форм (`Form.xml`) используется
  другой механизм.
- Работает только с элементами на форме справочника (`Catalog/`). Аналогичная
  логика применима к документам (`Document/`) с адаптацией пути и имён файлов.

## Требования

- Исходники распакованы через v8unpack
- Файлы `CatalogForm.elem.json` и `CatalogForm.json` присутствуют в директории
  формы
