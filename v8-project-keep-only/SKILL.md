# v8-project-keep-only

**Важно:** Операция удаления проектов необратима. Скрипт автоматически делает бэкап `v8.projects.json` перед изменением.

Этот скилл нужен для массовой очистки: вы задаёте список проектов, которые должны остаться, и все остальные проекты удаляются из `v8.projects.json`.

## Когда использовать

- Пользователь говорит: «оставь только проекты A, B», «удали все кроме A и B», «prune projects»
- Нужно быстро убрать большое количество устаревших проектов

Ключевые слова: `оставь только`, `удали все кроме`, `очистить проекты`, `keep only projects`, `prune projects`.

## Решения и ветвления

1. Если нужно полное удаление следов проекта:
   - Запуск без дополнительных флагов (удаляет `src`, `build`, `temp`, `current`)
2. Если нужно сохранить папки удаляемых проектов:
   - Запуск с `-KeepFolders`

## Порядок действий агента

1. Получить от пользователя точный список проектов, которые нужно оставить.
2. Подтвердить режим удаления:
   - по умолчанию: JSON + удаление папок
   - при необходимости сохранить папки: использовать `-KeepFolders`
3. Запустить скрипт:

```powershell
# Оставить только перечисленные проекты (JSON + удаление папок остальных)
powershell -ExecutionPolicy Bypass -File .\.github\skills\v8-project-keep-only\scripts\keep-only-projects.ps1 -Projects "NLTrade,NLTrade_invoice"

# Оставить только перечисленные проекты, но сохранить папки удаляемых проектов
powershell -ExecutionPolicy Bypass -File .\.github\skills\v8-project-keep-only\scripts\keep-only-projects.ps1 -Projects "NLTrade,NLTrade_invoice" -KeepFolders

# Без подтверждения (например, в CI)
powershell -ExecutionPolicy Bypass -File .\.github\skills\v8-project-keep-only\scripts\keep-only-projects.ps1 -Projects "NLTrade,NLTrade_invoice" -Force
```

4. Показать пользователю:
   - какие проекты оставлены
   - какие удалены
   - путь к бэкапу `v8.projects.json`

## Критерии завершения

- В `v8.projects.json` в секции `projects` остались только запрошенные проекты
- Все неуказанные проекты удалены
- По умолчанию удалены соответствующие папки проектов (или сохранены при `-KeepFolders`)
- Создан бэкап JSON перед модификацией

## Результат

- Workspace содержит только нужные проекты (по JSON)
- По умолчанию удалены данные лишних проектов на диске
- Конфигурация стала чище и проще для дальнейших операций
