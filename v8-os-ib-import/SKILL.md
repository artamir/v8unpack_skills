# v8-os-ib-import

## Описание

**Важно:** Запускайте скрипты в соответствующей среде: файлы с расширением `.os` — только через `oscript`, файлы с расширением `.ps1` — только через PowerShell.

Скилл позволяет загружать конфигурацию 1С из файла .cf в базу (путь к которой указан в секции current проекта) с помощью v8-runner.bat и vrunner. Все параметры путей и логин берутся из v8.projects.ini.

- Определяет путь к базе и cf-файлу из секции [project.<Имя>] → current/current_cf
- По умолчанию использует логин из [project.<Имя>.logins.default] (db_user/db_pwd)
- Формирует команду для vrunner (через v8-runner.bat) для загрузки cf
- Сообщает об ошибках, если база, cf-файл или логин не указаны

## Использование

- "загрузи cf для NLTrade"
- "импортируй NLTrade.cf в базу"
- "импортируй cf в NLTrade"

## Пример вызова

    .github/skills/.tools/oscript/v8-runner.bat load --ibconnection "/F<путь_к_базе>" --src <путь_к_cf> --db-user <db_user> --db-pwd <db_pwd>

**Важно:**
- Для файловой базы параметр --ibconnection должен быть в формате `/F<путь_к_каталогу_базы>` (без пробела между /F и путём)
- Если база требует авторизации, добавьте параметры `--db-user <пользователь>` и `--db-pwd <пароль>`

## Требования
- v8-runner.bat, ovm.exe и vrunner должны быть зарегистрированы в секции [tools] v8.projects.ini
- В секции [project.<Имя>] должен быть указан параметр current
- cf-файл должен быть выгружен из этой базы и не изменён (гарантия успешной загрузки без ошибок)
