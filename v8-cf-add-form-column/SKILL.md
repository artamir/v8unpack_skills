# v8-cf-add-form-column

## Описание

Скилл добавляет новую колонку в табличную часть на форме 1С (обычная форма, `DocumentForm.elem.json`).

Поддерживаемый формат: форма, где колонки таблицы хранятся как дочерние элементы (`child`) в `tree`.

### Что делает скрипт

1. Находит таблицу по имени в разделе `tree` файла `DocumentForm.elem.json`
2. Берёт первую существующую колонку таблицы как шаблон
3. Клонирует её raw-данные, заменяя:
   - системное имя колонки (в 3 местах: сама колонка, контекстное меню, расширенная подсказка)
   - локальные ID элементов (col_id, ctx_menu_id = col_id+1, hint_id = col_id+2)
4. Добавляет новый элемент `{"name": "...", "type": "Field"}` в `child` таблицы в `tree`
5. Добавляет запись `"ТаблицаKey/НоваяКолонка"` в `data`
6. Обновляет счётчик ID формы в `DocumentForm.json` (`form[0][0][1][0]`)
7. Создаёт бэкапы обоих файлов перед изменением

### Ключевые структуры

**tree** — иерархия элементов формы:
```json
{"name": "Список", "type": "Table", "child": [
  {"name": "Дата", "type": "Field"},
  {"name": "Сумма", "type": "Field"}
]}
```

**data** — расширенные свойства каждого элемента:
```json
{
  "Список": { "ver": 27, "raw": [...] },
  "Список/Дата": { "ver": 4, "raw": [35, ["16", "form-uuid"], ...] },
  "Список/Сумма": { "ver": 4, "raw": [35, ["34", "form-uuid"], ...] }
}
```

**Структура raw для колонки:**
- `raw[0]` = 35 (маркер типа "колонка таблицы")
- `raw[1]` = `["local_id", "form_uuid"]`
- `raw[4]` = 0 или 1 (смещение позиции имени)
- `raw[6]` или `raw[7]` = `'"ИмяКолонки"'` (имя в кавычках 1С-стиля)
- `raw[42/43]` — блок контекстного меню (ID = col_id + 1)
- `raw[52/53]` — блок расширенной подсказки (ID = col_id + 2)

**Счётчик ID** в `DocumentForm.json`:
- Путь: `form[0][0][1][0]` (строка, например `"49"`)
- Содержит максимальный занятый ID; при добавлении колонки обновляется на `new_hint_id`

## Использование (через Copilot)

- "добавь колонку СуммаРасходов в таблицу Товары формы ФормаДокумента документа ВводЗатрат"
- "добавь колонку в табличную часть формы"

## Форма вызова скрипта

```bash
python tools/add_form_column.py <путь_к_elem_json> <ИмяТаблицы> <ИмяКолонки> ["Заголовок колонки"]
```

**Параметры:**
- `путь_к_elem_json` — абсолютный или относительный путь к `DocumentForm.elem.json`
- `ИмяТаблицы` — системное имя таблицы на форме (например `Список`, `Товары`)
- `ИмяКолонки` — системное имя новой колонки
- `Заголовок колонки` — необязательно; если не указан, равен имени колонки

## Примеры

```bash
# Добавить колонку в форму списка документа ЧекККМ
python tools/add_form_column.py \
  src/NLTrade_invoice/Document/ЧекККМ/DocumentForm/ФормаСписка/DocumentForm.elem.json \
  Список НоваяКолонка "Новая колонка"

# Добавить колонку без заголовка
python tools/add_form_column.py \
  src/NLTrade_invoice/Document/ВводЗатрат/DocumentForm/ФормаДокумента/DocumentForm.elem.json \
  Товары БазаРаспределения
```

## Что НЕ поддерживается

- Старый формат колонок: колонки встроены в `raw[2][2]` таблицы (нет `child` в tree). Такие таблицы встречаются в старых формах документов (например `ВводЗатрат`).
- Указание ширины, типа данных, привязки к реквизиту объекта — колонка создаётся как копия шаблонной; дополнительную настройку выполните вручную в конфигураторе.

## Связанные скиллы

- `v8-cf-v8pack` — запаковка CF после изменений
- `v8-os-ib-import` — загрузка CF в базу 1С
- `v8-cf-add-object` — добавление новых объектов метаданных (перечислений и др.)

## Требования

- Python 3.8+
- Файл `DocumentForm.json` должен находиться в той же папке, что и `DocumentForm.elem.json`
