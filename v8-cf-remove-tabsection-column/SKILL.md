# v8-cf-remove-tabsection-column

## Описание

Скилл удаляет колонку из табличной части справочника в исходниках распакованной конфигурации 1С (v8unpack-формат).

- Удаляет запись колонки из списка колонок ТЧ (`ts_entry[2]`)
- Уменьшает счётчик колонок в `ts_entry[2][1]`
- Перезаписывает `Catalog.tabular_sections.json`

## Использование

- «удали колонку Реквизит1Строка10 из табличной части ТабличнаяЧасть1 справочника Справочник01»
- «remove column Реквизит1Строка10 from tabular section ТабличнаяЧасть1 of Справочник01»

## Скрипт

Файл: `tools/remove_tabsection_column.py`

```
python tools/remove_tabsection_column.py <source_dir> <catalog_name> <ts_name> <col_name>
```

Аргументы:
- `source_dir` — путь к распакованным исходникам проекта (`src/<Проект>`)
- `catalog_name` — имя папки справочника (например, `Справочник01`)
- `ts_name` — имя табличной части (например, `ТабличнаяЧасть1`)
- `col_name` — имя удаляемой колонки (например, `Реквизит1Строка10`)

## Определение source_dir

Путь к исходникам берётся из `v8.projects.json`:

- Топ-уровневый проект (например, `BAU`): `projects.BAU.src` = `src/BAU`
- Подпроект (например, `BAU_KlientBank`): `projects.BAU.projects.BAU_KlientBank.src` = `src/BAU/BAU_KlientBank`

## Требования

- Исходники должны быть предварительно распакованы через v8unpack
- Если табличная часть не найдена: ответить «Ошибка: табличная часть <ts_name> не найдена в справочнике <catalog_name>.»
- Если колонка не найдена: ответить «Ошибка: колонка <col_name> не найдена в табличной части <ts_name>.»
