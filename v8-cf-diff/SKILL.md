# v8-cf-diff

## Назначение
Автоматизация проверки целостности изменений исходников 1С: упаковка в cf, распаковка cf во временную папку и сравнение содержимого файлов.


## Порядок проверки
1. Сначала запаковываются актуальные исходники проекта в .cf с помощью скилла `v8-cf-v8pack`.
2. Скопировать созданный cf-файл в папку `temp/<ИмяПроекта>/`.
3. Распаковать cf-файл из папки `temp/<ИмяПроекта>/` во временную папку с помощью скилла `v8-cf-v8unpack`.
4. Сравнить исходники и распакованную временную папку с помощью v8-cf-diff (инструмент сравнения исходников).
5. Если различия есть — зафиксировать и проанализировать причину. Если различий нет — изменения в исходниках корректны.

## Требования
- Скрипт-обёртка для запуска всех этапов, создания недостающих папок и логирования.
- Использовать только штатные скиллы для упаковки/распаковки cf, передавая им явные пути при работе с временными файлами.
- Уникальный суффикс формировать по дате/времени или GUID.

## Пример использования
- "Проверь целостность исходников NLTrade_invoice"
- "v8-cf-diff NLTrade"

## Критерии успешности
- Временный cf-файл создан и распакован без ошибок.
- Сравнение каталогов не выявило различий (или различия зафиксированы для анализа).

## Возможные доработки
- Автоматическое удаление временных файлов после проверки.
- Генерация подробного отчёта по найденным различиям.
