# v8-os-ib-export


## Описание

**Важно:** Запускайте скрипты в соответствующей среде: файлы с расширением `.os` — только через `oscript`, файлы с расширением `.ps1` — только через PowerShell.

Скилл позволяет выгружать конфигурацию 1С из базы (файлы которой указаны в current секции проекта) в файл cf, используя v8-runner.bat и vrunner. Все параметры путей и логин берутся из v8.projects.json.

- Определяет путь к базе из секции [project.<Имя>] → current
- По умолчанию использует логин из [project.<Имя>.logins.default] (db_user/db_pwd)
- Формирует команду для vrunner (через v8-runner.bat) для выгрузки cf
- Поддерживает указание имени выходного файла cf
- Сообщает об ошибках, если база не найдена, путь или логин не указан

## Использование

- "выгрузи cf для NLTrade"
- "экспортируй конфигурацию NLTrade в файл apam.cf"

## Пример вызова

    .github/skills/.tools/oscript/v8-runner.bat export --ibconnection "/F <путь_к_базе>" --to <путь_к_cf>

## Требования
- v8-runner.bat, ovm.exe и vrunner должны быть зарегистрированы в секции [tools] v8.projects.json
- В секции [project.<Имя>] должен быть указан параметр current

## Связанные скиллы
- v8-os-vrunner — универсальный запуск vrunner
- v8-os-import — загрузка конфигурации из cf в базу
